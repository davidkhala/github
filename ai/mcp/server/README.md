# GitHub MCP server
> offers tools to list repositories, create pull requests, or manage issues.
- [source](https://github.com/github/github-mcp-server)


## Configure on VS Code
Using OAuth (Easiest)
```
{
  "servers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/"
    }
  }
}
```
